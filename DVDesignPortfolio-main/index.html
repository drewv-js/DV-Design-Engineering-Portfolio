01 / ONE PORTFOLIO, TWO PERSPECTIVES

interaction + state + accessibility
LIVE ON THIS SITE

The two-sided portfolio

A lightweight front-end build that connects design exploration with UX engineering. Try the switch above, then look behind the interaction.

HTML / CSS / JavaScriptResponsive UIKeyboard interaction
Behind the interface

One choice, consistent state

The hero buttons update the introduction, project collection, page title, and URL together. The selected button exposes its state to assistive technology.

Made for more than a mouse

Tab to either button and press Enter or Space. Focus stays on your choice, and a short announcement confirms the view. Decorative motion is disabled when reduced motion is requested.

A link to either side

The ?view=build URL opens this view directly. Back and Forward restore earlier choices. No account, tracking, or saved browser preference is needed.

Built without a framework

Both views live in the same static page. The inactive content is hidden from the layout and accessibility tree. Design remains available if JavaScript is disabled.
